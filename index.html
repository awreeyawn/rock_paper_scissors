Rock Paper Scissors Game

randomly pick a number 1-3 for rock, paper, or scissors

set the computer's choice to be either rock paper or scissors based on the random number

ask for user input for either rock, paper or scissors (ask user for actual choice, not 1-3)

then compare the choices to determine the winner (paper beats rock, rock beats scissors, scissors beats paper)

decide the winner of the game based what the computer and the user chose
